## 📝 Notes
- Loops only VISIT elements; indices define the real transformation.
- `i - K` means shifting current element left by K positions.
- `n - K + i` means shifting current element right by n-K positions.
- Reading index and writing index can be different.
- First loop handles elements from `K -> n-1`.
- Second loop handles elements from `0 -> K-1`.

## 🧠 Concepts
- **Array Rotation:** Moving array elements cyclically left or right.
- **Index Transformation:** Converting old element positions into new positions.
- **Traversal Index:** Index used for reading original array elements.
- **Placement Index:** Index used for writing elements into transformed positions.
- **Left Shift:** Moving element toward smaller indices.
- **Right Shift:** Moving element toward larger indices.
